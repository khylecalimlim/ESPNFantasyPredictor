# ESPN Fantasy Predictor

A draft assistant and weekly performance backtester for a Full PPR ESPN Fantasy Football
league — train and tune a model while watching it draft (pick-by-pick, adjustable speed) and
score it against real historical weeks.

See [ROADMAP.md](./ROADMAP.md) for the full step-by-step plan.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Then launch notebooks with `jupyter notebook` (or open `notebooks/` in your editor of choice)
from within the activated environment.
